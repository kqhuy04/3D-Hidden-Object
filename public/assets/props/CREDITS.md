# Prop credits

The rod the player holds while fishing. A free low-poly model from Polyfork,
used under CC BY 4.0 — the credit line below is the attribution that licence
asks for. The file is hosted locally so the game keeps working offline (it
ships as a Tauri desktop app).

| Prop | Asset | Licence |
| --- | --- | --- |
| Fishing rod | Propped fishing rod by Polyfork (https://polyfork.dev/asset/propped-fishing-rod-072978), CC BY 4.0 | CC BY 4.0 |

The model is authored as a rod *propped on a forked stick*, with a line and a
float hanging off it. The stick is removed by name at load and the modelled
line is removed by triangle, because the game draws its own line from the tip
to wherever the float actually landed. What is left is 2.2 m of rod with a
cork handle and a crank the reeling animation turns.
