# 2026-11-13

## Performance audit (read-only, user asked: no code changes, no quality loss)

Read the whole hot path. Findings, in priority order, with the numbers that made
them findings (measurements from GLB JSON chunks, not guesses):

- `frontier-town`: 2088 prims / **599 materials** / 327 skinned nodes / 429k tris.
  `office`: 1488 prims / **1047 materials** / 354k tris. `symphony-stagecraft`:
  1519 prims / 925 materials / **1.18M tris**. Materials are unique per prop, so
  draw calls ≈ visible prims and each one is a state change.
- **Off-heightfield landmine**: `WorldCollision.getGroundHeight` falls back to
  `raycastGround` (full-mesh `Raycaster`) and `moveCapsule` calls it 3×/frame
  (281, 296, 459) + `groundAt` from `slopeScale`. 6.2 ms per query measured
  before → 10–25 ms/frame on a reef/dock edge. Use `terrainHeight` + last-known.
- **Shadow world rebuild** (1423 draws / 372k tris) still lands in one frame every
  6 m walked (`ANCHOR_SNAP_XZ = 6`). Quality-neutral fix = scrolling strip.
- `InteractableSelector.update` can spend up to 10 full-scene rays in one frame
  (cache TTL 200 ms / 0.5 m, both expire together).
- `NpcCrowd.startLeg`: 12 attempts × 6 samples × `groundAt` = up to 648
  `supportHeight` sweeps in one frame, ~1×/s.
- Collision has **no spatial index over parts**: `supportHeight` × 9 probes,
  `collectContacts` × 4 per substep, `deepestContact`, `raycastSegment` all loop
  every part and every triangle of a part whose box contains the point.
- Found screen: full-viewport `backdrop-filter: blur(13px)` + second GL context
  while the game keeps rendering at full rate.
- `composite()` blits the whole shadow map every frame (erase movers) — scissor
  to the mover rects.
- 327 skinned props on frontier-town are static but still pay the skinning path.

## Batch 1 shipped (same day)

Measured first, and the measurement changed two conclusions:

- **The 6.2 ms raycast landmine is real but narrow.** `getGroundHeight` only
  falls back to `raycastGround` where `sampleHeightField` returns null *and* the
  ray still meets the mesh's bounding sphere — i.e. a band just outside the
  rasterised grid. Far-away probes cost 0.0005 ms (three early-outs on the
  sphere), which is why a naive measurement said "not a problem". At the real
  spot on `coral-reef`: **13.6–17 ms per query**, and the walk called it 4× a
  frame.
- **Only 10 of 21 maps have a terrain node at all.** `cozy-farm`, `office`,
  `nyc-city`, `symphony-stagecraft` and six others have no `-terrain`/`ground`
  node, so they have no heightfield and their ground is an ordinary collision
  part. On those maps the fallback returns 0 instantly and the whole issue is
  moot. `WorldCollision.terrainHeight` returning null is the tell.
- Per-frame cost of one `moveCapsule`: **0.456 ms** (`nyc-city`, 204 parts /
  89k tris), **0.881 ms** (`cozy-farm`, 480 parts / 183k tris). That is the
  batch-2 target and it is bigger than estimated — the 9-probe `supportHeight`
  over every part is the cost, not the raycast.

Changes: `groundNear` (heightfield → last-known) used by `moveCapsule` and
`groundAt`, exact `getGroundHeight` kept for spawn/placement; `RAYS_PER_FRAME=2`
in the selector with items always ray-tested and the rest taken on trust for a
frame; `TargetOutline.warm` + `FoundStage.warm` called from the loading screen;
`Game.render(force)` skips every other frame while the found screen is up
(`onWindowResize` passes `true`, or the buffer stays black); two per-frame
allocations removed (`PlayerController` step vector, `Mounts` saddle point, plus
`updateWorldMatrix(true,false)` instead of the whole subtree).

Dropped: the scissored shadow blit. `setScissor` is multiplied by the canvas
pixel ratio, not the render target's size, and the adaptive scaler changes that
ratio mid-round — the failure mode is a ghost shadow, silently.

Verified: typecheck clean, 118/118 tests, smoke on `nyc-city` + `coral-reef`
(console clean, 6 render calls → 3 drawn with the veil up). Prompt latency probe
showed no regression once the run-to-run noise was accounted for (baseline ran
twice: cannon 5/12 frame 7 both times).
